# Python Data Structures and Algorithms

Selected Python coursework demonstrating core programming, data-structure, and algorithm concepts.

## Included Work

### Checkout Queue Simulation

`queues/checkout_queue_simulation.py`

A queue-based simulation that uses circular queue behavior to add and remove customers from multiple checkout lines.

### Graph Algorithms

`graphs/graph_algorithms.py`

Graph-focused work using vertices, adjacency relationships, stacks, depth-first traversal, spanning-tree logic, topological sorting, degree calculations, and clique-related logic.

## Why These Files

These examples were selected from a larger set of programming assignments because they show different kinds of problem solving: stateful queue simulation and more advanced graph traversal/analysis.

## Attribution

Some coursework used instructor/textbook-provided starter implementations that were modified or extended as part of the assignments. Existing attribution and modification comments have been preserved in the source files.
